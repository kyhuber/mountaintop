# Playing card artwork

The 52 SVG card faces are from **Vector Playing Cards** by Byron Knoll,
released into the public domain. They include traditional suit pip arrangements
and illustrated court cards. No artwork purchase or royalty is required.

- Original project: https://code.google.com/archive/p/vector-playing-cards/
- Creator's public-domain release: https://byronknoll.blogspot.com/2011/03/vector-playing-cards.html
- Face-card release: https://byronknoll.blogspot.com/2011/03/face-cards.html
- Source mirror: https://github.com/adamlacoste/vector-playing-cards
- Source commit: bd9cfc6f13674fe9d4c0bd32a5c9ca2c1b56185d

SVG artwork is unmodified. The illustrated court variants (jack, queen, and king
filenames ending in `2.svg` upstream) are renamed without the `2` suffix here.
Only the 52 playing faces are bundled; symbolic court variants and jokers are
omitted. Artwork is served with the game, without a CDN or
an external image service. The existing build copies this directory into dist.
